# Defenspace

**▶ 立即遊玩：https://rjian-collab.github.io/Defenspace/**

艦橋即時射控遊戲。站在戰艦艦橋上，一邊用準星攻擊移動中的敵艦，一邊攔截來襲彈頭、張開三向護盾。

- 封面：`index.html`
- 遊戲：`play.html`（單一檔案，含 three.js 與全部音效）

## 怎麼玩
- 電腦：滑鼠瞄準、點擊發射；Q/W/E 換武器；1/2/3 張開左舷／艦首／右舷護盾；P 暫停；H 說明。
- 手機（建議橫放）：手指點哪裡準星就到哪裡，點到紅色或黃色彈頭直接發射 ABM 攔截。

船艦模型、音效與畫面皆為程式原創生成。
